Test Selection Map
Confidence Intervals
Estimating
Uncertainty
Formulas
CI = x̄ ± z*·(σ/√n) Known σ
CI = x̄ ± t*·(s/√n) Unknown σ
CI = p̂ ± z*·√(p̂(1−p̂)/n) Proportion
Critical z* Values
90% CIz* = 1.645
95% CIz* = 1.960
99% CIz* = 2.576
Interpretation
"95% CI [0.42, 0.58]" means: if the study were repeated many times, 95% of constructed intervals would contain the true parameter. It does not state a 95% probability the true value lies inside this specific interval.
Effect Sizes
Practical
Significance
Standardised Measures
Cohen's d = (μ₁−μ₂)/s_p Mean difference
r = √(t²/(t²+df)) Correlation
η² = SS_effect/SS_total ANOVA variance
OR = (a/b)/(c/d) Odds Ratio
Cohen's d Benchmarks
d=0.2 Small
d=0.5 Medium
d=0.8 Large
Critical Note
Statistical significance ≠ practical significance. Large samples can produce p<0.001 with d=0.05 (negligible effect). Always report both p-values and effect sizes together.
CLT
Central Limit Theorem: sample means approach Normal distribution as n→∞
MLE
Maximum Likelihood Estimation: parameters maximising P(data|θ)
OLS
Ordinary Least Squares: minimises Σ(y−ŷ)² in linear regression
MAP
Maximum A Posteriori: Bayesian point estimate at posterior mode
MCMC
Markov Chain Monte Carlo: samples from complex posterior distributions
FDR
False Discovery Rate: expected proportion of false positives (Benjamini–Hochberg)
VIF
Variance Inflation Factor: detects multicollinearity; VIF >10 is a concern
KDE
Kernel Density Estimation: non-parametric smooth density estimator
